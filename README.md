# 倒立摆

倒立摆系统的动力学、可达性与控制研究。

项目以数学推导为起点，通过可复核的数值实验检验理论，再将经过验证的结果实现为可独立使用的工程工具。不同倒立摆模型作为独立课题组织在同一个仓库中。

## 当前课题

**[受限空间三重倒立摆](studies/obstacle-constrained-triple-pendulum/README.md)**

研究三根串联摆杆在单输入驱动、障碍物和执行器约束下的构型转换。初始目标是建立完整的非线性动力学模型，分析无碰撞构型空间、动力学可达性与转换代价，寻找具有严格依据的可行性条件与算法结构。

## 研究方法

1. **建立模型**：明确几何、质量、惯量、关节、输入与障碍约束，推导动力学方程。
2. **研究结构**：从能量、对称性、拓扑、可达性及控制约束寻找可证明的结论。
3. **数值验证**：在明确的参数和误差控制下复核推导，记录可复现的轨迹与反例。
4. **工程实现**：围绕已形成的数学结果设计求解、分析、可视化与导出功能。

## 课题组织

每个课题独立记录问题定义、模型约定、已证结论、待检验命题和实验结果。新模型可逐步加入 `studies/`。
