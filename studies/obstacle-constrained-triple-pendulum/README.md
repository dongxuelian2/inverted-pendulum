# 受限空间三重倒立摆

## 研究对象

三根刚性摆杆组成平面串联系统，底部固定，初始设定只有基座关节可以施加控制转矩。摆杆在存在障碍物的有限空间内运动，目标是在给定约束下完成下垂构型到倒立构型的转换，并在目标邻域保持稳定。

本研究首先采用平面模型。质量分布、关节阻尼、碰撞几何、输入及时间限制均在正式推导中明确列出，后续扩展可独立建模。

## 动力学模型

以相邻杆之间的相对角定义广义坐标

\[
q=(q_1,q_2,q_3)^\mathsf T,\quad x=(q,\dot q).
\]

在这一坐标约定下，目标模型为

\[
M(q)\ddot q+C(q,\dot q)\dot q+g(q)+f(q,\dot q)=Bu,\qquad B=(1,0,0)^\mathsf T,
\]

其中 `M` 是质量矩阵，`C` 表示速度耦合，`g` 为重力广义力，`f` 包含待明确的关节耗散项，`u` 为基座驱动转矩。实际方程由拉格朗日推导确定，并使用独立数值实现交叉核对。

## 约束与任务

设各摆杆占据的几何区域为 `S(q)`，障碍集合为 `O`。无碰撞构型空间定义为

\[
\mathcal C_{\mathrm{free}}=\{q:S(q)\cap O=\varnothing\}.
\]

控制转矩满足 `|u(t)| <= tau_max`，并可加入关节限位、速度限制及指定转换时间 `T`。研究固定初态与目标平衡态之间的可达性；若采用相对角坐标并以竖直下垂为零角，两个典型构型分别为 `q=(0,0,0)` 和 `q=(pi,0,0)`。

需要分别分析：

- **几何条件**：自由构型空间的连通分支、障碍布局和对称性；路径连通是无碰撞转换的必要条件。
- **动力学条件**：控制输入受限时的状态可达性、能量传递和稳定化。
- **优化条件**：转换时间、转矩峰值及控制努力之间的权衡，研究可证明的下界与可行轨迹。
- **数值可靠性**：独立积分器交叉验证、时间步长收敛、碰撞检测精度与失败轨迹复现。

## 近期数学工作

1. 推导惯性矩阵、科氏/离心项、重力项以及能量表达式；明确所有变量和参数的物理单位。
2. 选取可明确描述的障碍物布局，建立其无碰撞构型空间并分析连通性。
3. 在给定输入界与初末状态下，寻找可达性必要条件、能量与时间下界；区分严格证明和数值观察。
4. 调查三重欠驱动摆、受障碍约束轨迹优化与受限可达性文献，整理已经解决的问题。
5. 在形成清晰数学命题后，编写最小数值检验程序，并选择可复现的优化方法作为比较基线。

## 工程目标

将数学结果实现为一个可独立运行的工具：用户定义杆件和障碍参数、驱动约束及起终构型，获得可行轨迹、约束检查、理论界限（如有）和运动可视化。工程范围随已验证的数学成果逐步确定。
